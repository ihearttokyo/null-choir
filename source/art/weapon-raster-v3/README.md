## Registration and replay
Ranged forward emission/endcaps map to native140,62, corresponding to the unchanged HUD effect center. Rear glowing feed chambers are not falsely treated as muzzles. Impact tool uses documented grip/ram registration, preserves actual head compression travel and has no ranged flash. Origin160,200 and HUD rectangle180,143,320,200 remain unchanged. One uniform scale is used within each weapon, with actual perpose source landmarks and explicit crops.

To reproduce, make a **fresh disposable directory** for one weapon containing its original `production-source-v1.png` and exact registration JSON, but not its accepted `candidate-*` directory. Invoke the recorded compiler through official Godot `--headless --audio-driver Dummy --script ABS_COMPILER -- --registration=ABS_FRESH_REGISTRATION`. The script refuses existing output overwrites; its `native_output` field preserves the original relative output layout. Rivet uses `compilers/rivet_compile_registered_atlas.gd`; the other five use `compilers/compile_weapon_atlas.gd`. Compare the outputPNG/pixel SHA to the ledger/proof. No private workspace or original image generator is needed for this deterministic extraction replay.
