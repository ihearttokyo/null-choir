# Healing-machine source/runtime kit v1

Eight original polygonal families derived from the retained eight-rig reference, with actual P96 reservoir-ivory and reservoir-final failure images inspected. These assets and their runtime adapter are integrated in the canonical source tree. Actual native import and scoped in-game geometry, stock, interaction, physics-LOS, recovery and intended-use visual checks have now passed for the v0.096 candidate. Packaging/publication is still pending; these checks are not a full-campaign or human-play certification.

## Editable sources and exports
- `source/generate.py`: deterministic, stdlib-only mesh generator, eight designs, meter units, Y-up/front -Z. No Blender, GPU, game engine or API invocation.
- `models/*.gltf` + matching `.bin`: editable glTF geometry with one shared external `../raw/texture-atlas.png`.
- `models/*.glb`: compact runtime alternatives, internal geometry buffer but the same external shared PNG. Keep `models/` beside `raw/` when moving the kit. Neither format embeds eight atlas copies.
- `metadata/*.json`: part names/roles, material tile indices, per-part bounds, authored stock bounds and interaction positions. `metadata/atlas-tiles.json` defines the fixed 4×4 atlas contract, top-left origin.
- `source/blender_import_save.py`: retained **unrun** import/pack/master-save script for later explicitly authorized Blender execution. No `.blend` files or native8K masters presently exist.

Families: hanging pressure bulb; refractory ceramic crucible; three-column capillary organ; ivory archive vessel; nonfigurative clinical capsule (no infant); ribbed marrow tank; canted supported orbit core; organic valve cage. All use broad ivory/steel framed structure, substantial vessels, brass-connected handwheel controls, floor plinth/flanges/anchor bolts and a rear feed/conduit.

## Runtime integration contract (source and scoped native checks passed)
Find exact node names `UseTarget`, `StockVolume`, `StockNeedle`. The visible handwheel/dial lies at the front-right three-quarter corner. `UseTarget` is an empty interaction anchor in front of it. Part nodes remain separate/editable (no cube with pasted concept art).

`StockVolume` local mesh Y is 0…1. Preserve its translation (authored bottom) and X/Z scale, set Y scale to `fullHeightMeters * fraction`. At zero, hide it and PRESERVE its full authored nonzero scale; rendered empty means zero visible stock, not zero geometric height. Never set any scale component to zero. The retained non-rendered geometry still occupies full bounds and has an invertible transform. Bounds and full/half/empty arithmetic are checked, not live gameplay/save/collision behavior. The gauge atlas contains markings only. `StockNeedle` is real geometry, not a truthful live meter until runtime drives its local rotation around the dial center; do not infer stock from the static default needle.

Paint-led `KHR_materials_unlit` materials use authored `COLOR_0` facet values for intrinsic legibility, not physical illumination, emission, global ambient fill or a whole glowing object. Structural separation and dark recesses remain geometric. Atlas is root-owned; no image editing is performed by this generator. UVs use a 4% inset in each named tile; quads share coherent triangulation. Sampler clamp, bilinear minification (no mipmap requested) reduce cross-tile bleed; engine override behavior needs native inspection.

## Checks and exact limits
`source/validate.py` verifies the exact shared PNG SHA256, dimensions, decoded alpha, OPAQUE unlit material/URI/color contracts, and reads actual exported buffers, tests finite positions, unit normals, nondegenerate triangles, index bounds, tile-contained UVs, unique node names, GLB headers/shared external image URI, family dimensions, and anchored full/half stock bounds plus hidden/nonzero-scale empty state. It also checks capillary central housing clearance, hanging/orbit physical drain overlap, and structural baffle/non-stock fluid-material constraints. `metadata/validation.json` is machine-readable. `SHA256SUMS.txt` hashes retained output/source artifacts (excluding itself and Python cache). Diagnostic PNG uses simple CPU projection and flat stand-in tile swatches, **not the atlas, Godot renderer, physical lighting, in-game contrast or art acceptance**. `source/diagnostic.py` uses existing Pillow only; generator and geometry checks require only Python stdlib; decoded PNG verification uses existing Pillow (no installation).

Actual native checks cover eight families,32stations and717 render/shape/material pins, synchronized physics-LOS positive/negative controls and current640×360 route/transaction views, plus finite-stock recovery. The adapter is `game/scripts/healing_machinery.gd` with Level/runtime/controller bindings. Preserve originals; the automated scope is not universal playability or performance certification.

## Portable runtime-contract recipe
`runtime_contract/build_registry.py` reproduces `game/data/healing_machinery_registry.json` from the retained source geometry and image. Run `python3 -B source/art/healing_machinery/runtime_contract/build_registry.py --check` from the repository (other working directories are supported). The default is read-only comparison; `--stdout` emits exact generated bytes, and explicit `--output PATH` creates only a new file without overwriting. `runtime_contract/render_contract.py` retains the declared render-attribute encoding convention. The fixed9efc source-kit manifest value is a historical provenance anchor, not this public directory's changing `SHA256SUMS.txt`.

`tests/test_healing_machinery_sources.py` checks actual source/runtime payload equality, registry reconstruction, render/collision mutations, image and material mapping, import settings and source lifecycle contracts. These Python checks do not execute Godot or prove native4.7.2 encoding, physics, performance, Space input or art quality. No upscaled8K, Blender master or Pro-output claim is made.
