# Earned Processional Organ loop

The fixture continues the accepted first-two-map campaign and Processional entry on the same Main, profile and original actors. It earns the first Organ branch's supplies and blood seal through actual virtual Input, then returns to the junction. The source test uses automatic native actor/player physics; it grants no resources, teleports nobody and directly damages no actor.

## Evidence

The accepted fixed-fps source path spends 37 pistol rounds during 3266 Organ physics frames, witnesses one original caster projectile birth and naturally defeats eleven third-map actors. It ends with 100 health, 140 armor, 174 pistol rounds, 32 shells and the blood seal. Five supplies are consumed once; the full-cap gate shells are rejected with their original marker retained. The route receives zero caster projectile hits, so positive earned-campaign projectile-damage attribution remains unproved.

Independent correctness and Ponytail reviews found three false-positive paths: missing birth delivery, deferred removal of a rejected marker, and a mutated loaded pickup amount. Each intentionally bad producer passed the old fixture. The corrected fixture rejects each at its intended guard and passes the unchanged normal route. It compares six independently frozen authored pickup records, admits every actual projectile birth, requires positive birth evidence, and checks final rejected-marker survival. JSON numeric literals match the loaded float representation without weakening strict dictionary equality.

A native timing failure also exposed premature test-input release: the physics-frame signal resumes before Main handles its buffered interaction. The fixture now holds the actual press through the process frame. The same held-input predicate and all route limits remain unchanged.

## Bounds and limits

Organ limits are 4000 native frames, 90 wall seconds, 240 frames per hop and 360 per fight. Earlier-map and entry limits are unchanged. Source-debug observation is exact birth/contact identity, not guessed queued damage. Native counterfactuals are deliberately invalid diagnostic producers, not ordinary acceptance runs.

This proves one earned loop, not the full third level or campaign. Physical input, rendered art/HUD quality, listening, GPU performance and packed-app attribution remain separate. The private standalone release is not rebuilt by this test-only change.
