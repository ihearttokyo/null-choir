# Earned Nursery entry

This source-native adapter extends the accepted Reliquary completion helper. It retains the same Main, Campaign and isolated profile, presses the actual connected Nursery menu button and returns the original fifth scene alive for later traversal. It does not recreate campaign state or grant inventory.

```sh
python3 tools/check_game.py --timeout 600 tests/test_nursery_earned_entry.gd
```

The unchanged four-map prefix earns 82 health, 170 armor, 162 rivets and 32 shells, weapons 0/1/2, selected weapon 1, difficulty 1 and discovery 3. The adapter verifies the independently derived fresh Nursery menu envelope and its loaded/file witness before retiring only `e_enabled`. All 51 remaining E fields and preceding history stay frozen.

The fifth scene contains the original 29 actors with authored roles, full HP, positions, yaws, groups and native capsules. Entry requires the original spawn, safe native floor/capsule support, same owner identities and one production capture attempt. Actual entry records replace unknown actors/facing in live checkpoint/current/start state; the disk keeps the unchanged earned menu envelope because this startup path does not save. Survey remains active and independently checked.

Fresh entry skips Main's restored-position awaits. The adapter observes the synchronous production start and two subsequent native registration frames; it does not force loaded placement or claim restored-only placement coverage.

## Limits

This proves source-native virtual menu input and fresh fifth entry, not Nursery combat/completion or all eight earned levels. Physical controls/mouse capture, rendered reference fidelity, audio/PCM/listening, sustained performance, current packed app and final release acceptance remain open. The original maps, art, music, preferences and production gameplay are unchanged.
