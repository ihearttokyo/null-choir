# Earned Ossuary transport loop

This source-native regression continues the accepted five-map route through Ossuary's first loop. It keeps the original Main, Campaign, profile, Level and Player. A separate witness tracks native damage, pickups, contacts and deaths while earlier observers remain frozen.

The route crosses the rib bridge, earns Blood through rebound-key input, clears the return encounter and reaches the junction. Ivory, Story, the launcher, transfer gate, finale and later maps are outside this slice. Sixteen original enemies must remain dormant and undamaged.

Its independent ledger ended at 100 health, 200 armor and ammunition [0,165,32,120,0,0]. The predecessor save remained unchanged. These are measured results, not a hardcoded cross-clock outcome oracle. Unbacked and duplicate actors are rejected. Removing the duplicate-instance guard makes the isolated negative control fail; unrelated capacity failures cannot mask it.

A separate wrong-pin copy refuses adoption before creating a scene or profile. Its single expected rejection error is qualified negative evidence, not a clean positive test. The current omitted-Blood run reached its absent-key/live-marker/frozen precondition, then produced only the intended refusal before the return encounter (315.278 seconds, expected exit1).

## Limits

Synthetic native input is not physical playtesting, visual fidelity, audio quality, GPU performance or packed-app acceptance. This slice does not complete Ossuary or the campaign.
