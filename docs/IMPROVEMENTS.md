# Improvement audit and delivery ledger

This ledger contains 64 distinct source-backed findings against `14a2e8d45879d72c680cf833ca2102e9d9ec220d`. Source findings are not measured performance gains or release certification. `S` means inspected source behavior, `D` means decoded actual asset data, and `X`/`I` means an experiment or usability inference. `s/` means `game/scripts/`; MIDI paths mean `game/addons/midi/`. Source line numbers refer to that baseline.

Native GREEN below means the stated regression passed in the local implementation; it does not mean published or merged. GPU appearance, physical controls and listening remain separate acceptance checks. Tuning candidates require paired representative evidence before promotion.

## Delivery completed locally

- Mac packaging validates a new ZIP and promotes it atomically, preserving the prior app on failure. Checksums stream rather than reading the complete archive into memory. Direct assertions cover promotion failure, permissions, CRC and temporary-file cleanup. A native rearchive of the published app is byte-identical and passes the standalone arm64 checks.
- Native test deadlines are explicit and finite; deadline changes do not weaken PASS/error/leak validation. Campaign and 24 late encounter cases pass at an explicit 150-second limit.
- An image-derived tactical survey reveals only locally visible routes, retains exploration through JSON saves and resource rewinds, resets per level, and supports rebound keyboard/gamepad actions. Native input and occlusion assertions pass; pixel validation remains pending. Actual generated reference and editable drawing source are retained.
- Checkpoint disk failures retain their cause in a memory-only warning. Dead Continue opens healthy recovery choices instead of recapturing gameplay; focus loss pauses and focus return requires explicit resume. Native checks pass; actual OS focus and GUI checks remain pending.
- Exact SoundFont selection reduces prepared presets from 18 to six and unique sample buffers from 507 to 166. In native measurements after repairing the common sample endpoint, selected PCM bytes fall from 28,339,054 to 10,021,256 (64.6%). This is selected PCM allocation, not whole-process RSS or a cold-start benchmark.

## Research used
